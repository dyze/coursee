# coursee: roadmap

Scope of each planned version. Implemented features move to [CHANGELOG.md](../CHANGELOG.md). The goal, principles and non-goals are in [GOAL.md](GOAL.md). The features are sorted by priority.

| Version | Status  | Theme     |
| ------- | ------- | --------- |
| 0.9     | Planned | To define |
## 0.9
1. Be able to tag an executable file (cmd, exe...) or a directory by right clicking on it in windows explorer. 
2. **Entry icons.** Rows show the entry's own icon (a game's or a file's exe icon) when it can be found, else the source icon.
3. **New icons.** Create new icons for UI.
4. **Donate.** Add a link to donate to the developer.

## Later
1. **Beautify changelog.** Today hard to identify the interesting info reading the md file as is.
2. **Outlook contacts source.** User can summon the display of email composing window with selected contact fed as recipient.
3. **Sign installer.** To make it more secure, use a certificate to sign all installers coming from the developer.
4. **End user manual.** A html manual is shipped with installer and available thru a "?" icon from App.
5. **Display scoring.** For helping debugging, the scoring of found entries is shown in the list.
